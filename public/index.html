Technical Architecture & Cryptographic Standards

          

            ScatterID provides an open reference architecture for post-quantum zero-knowledge digital identity.
          

        

      


      

        

          

            
NIST FIPS 204 (ML-DSA-65)

            Post-Quantum Signature
          

          

            Standardized in August 2024 by NIST. ML-DSA (Module-Lattice Digital Signature Algorithm) relies 
            on the hardness of lattice problems (Module Learning with Errors). Unlike RSA-2048 and ECDSA, 
            ML-DSA-65 remains unbreakable by Shor's algorithm on quantum computers.
          

          
    
            
  • Public Key Size: 1,952 bytes
    • 
            
  • Signature Size: 3,309 bytes
    • 
            
  • Security Level: NIST Category 3 (AES-192 equivalent)
    • 
          

        


        

          

            
RFC 8785 Canonicalization (JCS)

            Deterministic JSON
          

          

            Computers and programming languages serialize JSON differently (key order, spacing, floating-point formatting). 
            RFC 8785 guarantees that identical JSON objects serialize to the exact same byte string across Node.js, Python, 
            Go, and C runtimes.
          

          
    
            
  • Key Ordering: Strict UTF-16 code unit order
    • 
            
  • Whitespace: Completely stripped
    • 
            
  • Number Format: IEEE 754 deterministic serialization
    • 
          

        


        

          

            
Hyperledger Fabric Ledger

            Permissioned Consensus
          

          

            Enterprise distributed ledger running Raft crash fault tolerant (CFT) consensus. Stores credential 
            fingerprints and revocation states without storing sensitive user identities. Verifiers query the ledger 
            to ensure credentials haven't been revoked by the issuing authority.
          

          
    
            
  • Chaincode: scatterproof (Go contractapi)
    • 
            
  • Consensus: Raft Orderer
    • 
            
  • State Storage: Immutable ledger history + state database
    • 
          

        


        

          

            
HashiCorp Vault KMS

            HSM Key Isolation
          

          

            Master ML-DSA-65 signing keys are never stored on disk in plaintext. HashiCorp Vault manages key lifecycle, 
            cryptographic zeroization in memory, and allows one-click post-quantum key rotation without service downtime.
          

          
    
            
  • Auth: AppRole token authentication
    • 
            
  • Key Storage: Isolated KV v2 post-quantum secrets engine
    • 
            
  • Memory Hygiene: Explicit zeroization upon key rotation
    •
